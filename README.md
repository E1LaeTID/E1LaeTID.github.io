# E1LaeTID.github.io

Portail public des projets E1LaeTID : add-ons Blender, géométrie procédurale, modèle fractal universel, Time2D, carte calorique et ElementChess.

Site : https://e1laetid.github.io/

## Structure

- `index.html` : accueil et présentation générale ;
- `projects/` : familles de projets ;
- `timeline/` : progression historique ;
- `glossary/` : définitions ;
- `faq/` : réponses courantes ;
- `about/` : auteur, méthode et périmètre ;
- `robots.txt` et `sitemap.xml` : découverte par les moteurs.

Le site est statique et ne nécessite aucune compilation.
